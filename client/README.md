# CareerFlow Ultra X

CareerFlow Ultra X is an AI-powered career platform designed to help students and job seekers discover opportunities, build professional resumes, practice interviews, and manage applications.

## Features

- Job Search
- Internship Search
- Resume Builder
- AI Interview Practice
- Application Tracking
- Career Profile
- AI Career Coach

## Frontend

- React
- Vite
- CSS
